# Auto8D AI Generator

AI를 활용해 제조업 품질 이슈에 대한 **8D Report 초안**을 빠르게 생성하는 웹 서비스입니다.  
사용자가 제품명, 불량 현상, 발견공정을 입력하면, AI가 이를 바탕으로 D1~D8 형식의 개선 보고서 초안을 생성합니다.

---

## 1. 서비스 소개

### 서비스명
**Auto8D AI Generator**

### 서비스 목적
제조업 품질관리 업무에서 반복적으로 작성되는 8D Report 초안을 AI로 빠르게 생성하여,  
문서 작성 시간을 줄이고 문제 대응 방향을 빠르게 정리할 수 있도록 돕는 서비스입니다.

### 타겟 사용자
- 제조업 품질관리 담당자
- 생산기술 / 공정기술 담당자
- 불량 대응 및 고객 클레임 대응이 필요한 실무자
- 8D Report 초안 작성이 필요한 학습자 및 입문자

### 핵심 가치
- 제품명(필수) / 불량 현상(필수) / 발견공정(선택)만 입력하면 AI가 8D 초안 생성
- 결과를 D1~D8 항목별로 구분하여 가독성 있게 제공
- 품질 이슈 정리와 보고서 초안 작성 시간을 단축

## 2. 주요 기능

### [1] 메뉴 이동이 가능한 3개 섹션
- **Home**: 서비스 소개 및 시작 안내
- **AI Tool**: 8D Report 생성 기능
- **Guide**: 사용 방법 및 안내

### [2] AI 8D Report 생성
사용자가 아래 정보를 입력하면:
- 제품명 (필수)
- 불량 현상 (필수)
- 발견공정 (선택)

AI가 8D Report 초안을 생성합니다.

### [3] 결과 렌더링
생성 결과를 다음과 같이 출력합니다.
- 입력 요약 표시
- D1 ~ D8 항목별 카드 표시
- 일반 텍스트 응답인 경우에도 결과 표시 가능

### [4] 기본 예외 처리
다음 상황에서 사용자에게 안내 메시지를 제공합니다.
- 필수 입력 누락
- API 요청 실패
- 서버 오류 발생 시 재시도 안내

## 5. 실행 방법

### [1] 프로젝트 클론
```bash
git clone [https://github.com/U-an74/AI_Web_Service]
cd [auto8d-service]
```
### [2] 프론트 실행
정적 파일은 브라우저에서 열 수 있으며, 백엔드 API 연동 테스트는 로컬 서버 또는 Vercel 개발 환경에서 진행합니다.

```bash

```
- Vercel 설정    
   Vercel 프로젝트 접속	
   Settings
   Environment Variables
   환경 변수 이름과 값을 등록
   재배포

## 8. AI 기능 동작 방식
- 입력 
   제품명
   불량 현상
   발견 공정(선택)
- 처리
   JavaScript가 사용자 입력을 수집
   fetch()로 /api 엔드포인트에 POST 요청 전송
   Python 서버리스 함수가 AI API를 호출
   생성된 결과를 JSON으로 반환
- 출력
   화면에 생성 결과 표시
   D1 ~ D8 형식으로 구분 렌더링
   필요 시 일반 텍스트 형태도 표시

## 11. 한계 및 향후 개선 방향
- 현재 한계
    AI 응답 품질은 입력 내용과 프롬프트에 따라 달라질 수 있음.
    실제 기업에서 사용하는 8D 문서 형식과 100% 동일하지 않음.
    저장 기능 및 이력 관리 기능 없음.

- 개선 방향
    제조업 품질관리 관점의 프롬프트 고도화
    고객 클레임, 출하 영향, 격리/선별/출하 보류 중심의 문구 강화
    원인 분석에 4M + 공정 + 치공구 + 작업자 취급 관점을 반영
    결과 다운로드(PDF/텍스트) 기능 추가
    작성 이력 저장 기능 추가
